## 证据标签

- **当前客户端实测**：注明游戏版本、模式和可复核录像；目前本 Wiki 的争议项尚无这类证据。
- **官方历史公告**：证明公告对应版本的描述或修复，不能直接推定现版本。
- **玩家反馈**：玩家观察或确认的行为；缺录像时保留验证空间。
- **本地装备文案**：模拟所用目录快照的文字，不等同于客户端实测。
- **代码检查／模型假设**：只说明程序如何计算，不能写成游戏事实。

更新某个机制时，直接修订对应主题页，注明证据适用的版本、英雄和条件；如果会改变旧排名，在[压测口径](simulation/frontline-benchmark.md)中标出受影响的数据版本。这里不按日期堆积自查流水账。
