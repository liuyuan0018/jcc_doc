## 复用

下载原件集中在 `assets/`，来源与别名集中在 `catalog/assets.json`。SVG 自带图片，不依赖外部图片链接。新增阵容先复制 `lineups/裁决奶妈.json`，填入目录已有的准确名称；棋盘坐标行 0–3、列 0–6，不可重叠。模板固定四段标题、三条装备栏；长标题需重新查看排版。

```sh
python3 scripts/build_sample.py --skip-repair --lineup lineups/裁决奶妈.json --output exports/裁决奶妈-可复用模板-v1.svg
node scripts/export_png.cjs exports/裁决奶妈-可复用模板-v1.svg exports/裁决奶妈-可复用模板-v1.png
```

依赖：Python Pillow、Node sharp、中文字体。当前 Codex 本地环境可用随应用提供的运行环境。省略 `--skip-repair` 会同时重新生成 v3 局部修正版；原 v2 和认可原图不会被覆盖。

成品使用固定图片组合，不生成游戏图标。“防御装”等泛称只显示文字。新增素材必须记录名称、别名、赛季、来源及核验状态。
