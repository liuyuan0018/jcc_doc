# 蔚血手八套：当前模型定向核验

8 套均为三星蔚、6 主宰、6 人口、普通板甲与单身板甲独占一排；每档独立满血 30 秒，每秒减伤前来伤从 300 起按 50 递增。挑战护手为普通装 ID 618、索引 6。

- `results.json`：全部 277 个尝试档的结算，以及按最高连续通过档得到的并列名次。
- `source-replays.json`：1750—2250 连续展示所需 45 场真实回放。
- `verification.json`：当前修订模型源码及程序哈希、277 档逐帧守恒与旧存档结算对照、输入文件哈希。

最高通过：A 2200，E 2050，G 2000，C 1950，B 1900，D/F 1800 并列，H 1750。B 在 1950 第 900 帧 `alive=false`，属于失败。原设计 F/H 无普通板甲，冻结 CLI 拒绝启用单身板甲；正式八套使用策划修订后的 F/H，未混入无海克斯成绩。

这里是固定条件模型证据，不是实机对战。
