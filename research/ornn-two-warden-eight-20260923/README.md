# 两星奥恩／2 护卫：八套定向承压结果

2026-09-23。仅回答本次八套在同一固定条件下的模拟表现；不是旧奥恩三星／6 护卫成绩，也不是实机胜率或所有对局的装备排序。

## 固定条件

冻结 DataJ 场景 3：两星奥恩、2 护卫、2 人口。八套均为三件普通装备，无神器及神器进度；无指定海克斯，单身板甲和心之钢关闭。5 人集火参数、全程 33% 重伤、双抗各降 30%、来伤物魔各半、无控制；目标抗性沿用当前存档生产参数 50。每档独立满血模拟 30 秒，30 Hz，每秒 3 个来伤包。按减伤前来伤 DPS 每 50 一档，从 300 起试到首次失败。

300 档已经失败的 A、B、C、F、G，另向下实测 250、200、150、100、50，保留 300 原始失败；其最高通过档与首次失败档取这条连续网格中的相邻两档。D、E、H 从 300 通过到 350 首败。未在首次失败后向更高档外推。

## 输入、来源与核验

- [inputs.json](inputs.json)：场景、八组装备正式名／目录索引／ID、全部模拟参数。场景与装备目录来自冻结 v3；该场景没有可复用的 `raw` 结算，所以本次是新执行的定向计算。
- [results.json](results.json)：36 个实测档位的完整结算、观察范围、最高通过与首次失败。
- [verification.json](verification.json)：源文件和程序 SHA256、36 次逐帧生命／护盾收支及死亡事件检查、36 次独立重编译程序的完整输出对照、16 个末次通过／首次失败回放哈希。
