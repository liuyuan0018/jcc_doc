## 后续使用边界

DataJ作为金铲铲手游的优先资料核对来源；涉及争议机制，再对照同赛季、同版本的手游官方公告或客户端实测。PC TFT资料不能直接代替手游证据。统计胜率/排名用于选题参考，不能直接当作技能或装备公式。

制作每期时固定赛季、统计版本和原始资料快照；更新后先比较数值和规则，只重算受影响配置。已发布内容保留其原始输入，避免结果随网站更新而失去可复现性。

资料库内部 `season` 为 S19，而页面及 `setId` 为 S18；条目 `version` 也各不相同。原始字段全部保留，不自动把内部字段改写成页面版本，也不据字段名推定这是PC TFT数据。

本次没有修改模拟输入、算法、Unity代码或视频，也没有配置自动更新任务。
