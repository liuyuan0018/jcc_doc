# 当前评分：逐档压测，末档区间细分

本版取代 rammus-rank-integer-20260925 的任意最高通过点排名；旧扫描数据完整保留。

规则：全部 8365 套从 300 来伤起，每次加 50，首次失败即停止。只在最后通过档与首次失败档之间，从低到高每次加 1，首次失败停止；该流程的最后通过值作为成绩。后续更高来伤的重新通过不增加本榜成绩。这不是对所有更高来伤都无法通过的断言，也不是 300 起逐点扫描所得的连续边界。

全部方案使用同一规则，再按成绩降序确定全量名次；同成绩并列。保留原 64 套选择及各项海克斯，有无单身板甲独立比较。UI 使用“压测来伤”和“逐档压测成绩”，不再称任意最高通过值。

运行 `python3 -B research/rammus-rank-progression-20260925/regrade.py` 仅读取已验证 passRanges，校验归档 JSONL 哈希，重算分数与名次。此次未调用战斗模拟。8365 套粗档成绩均与旧逐档记录一致，Main 全部 83 个已展示战斗结果一致；64 套有 17 套分值改变，保留一组真实同分。

`ranking.json` 保留全部排名、旧最高值及粗档/细分边界；`main-consistency.json` 列出 Main 八套一致性证据；`replay.json` 是独立 Results 输入。当前完整视频输入为 `exports/frontline-rammus-eight-v1/production-v4/replay.json`，沿用原 Main 战斗，缩短全部静止口播。旧 v3 成片保留，但评分口径已被本次用户决定替代。
